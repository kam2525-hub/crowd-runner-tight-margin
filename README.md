# Crowd Runner: Tight Margin（群衆ランナー：ギリギリ生存戦）

プレイヤーが群衆を操作して奥へ走り、左右のゲート（足し算・掛け算など）を瞬時に選んで人数を増やし、ゴールに待ち構える敵の軍勢と相殺バトルを行う3Dランナーゲーム。

最大の特徴は**「ステージ自動生成（逆算生成）」**。常に「完璧に最適解を選んだ場合のみ、残数1〜3体でギリギリ勝利できる」難易度を逆算ロジックで生成します。

---

## 🎮 ゲームルール & コアサイクル

1. **スタート**: プレイヤーキャラクター1体から開始。前方へ自動前進します。
2. **道中操作**:
   - マウス移動 / ドラッグ
   - キーボード: `[A]` / `[D]` または `[←]` / `[→]`
   - スマホタッチ操作対応
3. **ゲート通過**: 2連ゲート（左/右）を通過すると、書かれた演算子（+10, ×2, -5 など）に応じて人数が増減。
4. **ゴール**: 敵の軍勢と激突し、1対1で相殺されます。プレイヤーが1体でも残ればステージクリア、全滅したらゲームオーバー。
5. **リトライ/次ステージ**: クリア時は次のランダム逆算生成ステージへ遷移。

---

## 🧮 「ギリギリ勝てる」ステージ逆算生成アルゴリズム

1. **ゲート対の数を決定**: 1ステージあたり 5〜7 箇所のゲートポイントを配置。
2. **正解ルートの確定**:
   - 初期値 $P_0 = 1$ から各ゲートで正解演算（`+N`, `×2`, `×3`）をシミュレーションし、最終想定人数 $P_{final}$ を算出。
3. **敵の人数の決定**:
   - 敵の人数 $E = P_{final} - \text{margin}$ （$\text{margin} = 1 \sim 3$）
   - 全問正解時のみ味方が1〜3体生き残り、1度でもハズレを選ぶと最終的に全滅確定となるシビアなバランス設定。
4. **ハズレゲート生成**:
   - 各ゲート対のもう片方は、正解ルートよりも結果が下回る数値を設定。
