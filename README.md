# Crowd Runner: Tight Margin（群衆ランナー：ギリギリ生存戦）

プレイヤーが群衆を操作して奥へ走り、左右のゲート（足し算・掛け算など）を瞬時に選んで人数を増やし、ゴールに待ち構える敵の軍勢と相殺バトルを行う3Dランナーゲーム。

最大の特徴は**「ステージ自動生成（逆算生成）」**。常に「完璧に最適解を選んだ場合のみ、残数1〜3体でギリギリ勝利できる」難易度を逆算ロジックで生成します。

---

## 🎮 主要システム & アップデート機能

### 1. 巨大メガボス（タイタンゴーレム）撃破バトル
- ゴール手前で前衛の雑魚敵部隊を相殺突破した後、奥に聳え立つ全高4倍の「メガボス（TITAN GOLEM）」と激突！
- 群衆が次々と飛びついてボスのHPバーをガリガリ削り、最後に大爆発で粉砕するダイナミックな演出。

### 2. フィーバータイム（無敵ダッシュ）
- 正解ゲートを3連続で通過すると**🔥 FEVER TIME**が発動！
- 群衆が巨大化＆超加速！回転トラップに突撃して粉砕破壊し、ボーナスコイン（+10🪙）を獲得できます。

### 3. 分かれ道ルート選択（ハイリスク・ハイリターン）
- コース途中に「⚠️ DANGER ZONE [×3]」と「🛡️ SAFE ZONE [+5]」の分岐が出現。
- 危険ルートはトラップが待ち構え道が狭いものの、コイン大量＆大増殖！逆算生成により、このリスクを取ることでメガボスを討伐できる爽快な戦略性を実現。

### 4. 人型キャラクター & サウンド
- 手足を元気に振って走る3D人型モデル。
- Web Audio API によるシンセサイザーBGM、効果音、ボスの咆哮・被弾音。
