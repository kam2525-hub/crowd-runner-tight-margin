# Crowd Runner: Tight Margin (Extreme Edition)

プレイヤーが群衆を操作して奥へ走り、左右の演算ゲートを瞬時に選んで人数を増やし、ゴールに待ち構える敵の軍勢＆巨大メガボスと激突する3Dランナーゲーム。

最大の特徴は**「ステージ逆算自動生成」**。常に「完璧に最適解を選んだ場合のみ、残数数体でギリギリ勝利できる」極限の難易度を誇ります。

---

## 🎮 主要システム & 大型追加要素 (v1.3)

### 1. 3大バイオーム環境変化
ステージクリアごとにコースの景色・ライティング・フォグ・ボスカラーが劇的に変化！
- **NEON CYBER (青/紫)**: サイバーパンクなネオン都市
- **LAVA VOLCANO (赤/橙)**: 溶岩が滾る危険な火山地帯
- **COSMIC GALAXY (マゼンタ/ディープシアン)**: 星々が煌めく宇宙空間

### 2. 特殊パワースフィア（道中アイテム）
道中に浮かぶ特殊アイテムを拾って一気に戦況を有利に！
- **🛡️ シールド**: トラップや衝撃波の被弾を1度だけ完全無効化するバリア。
- **🧲 マグネット**: 周囲のコインを自動で猛烈に吸引！
- **🔫 ブラスターキャノン**: 先頭からレーザービームを連射し、前方の回転トラップを遠距離狙撃粉砕（+10🪙ボーナス）！

### 3. メガボスの衝撃波スマッシュ
ゴール接近時、奥に聳え立つメガボスが巨大な腕を叩きつけて赤い**衝撃波リング**を放出してきます！左右のフットワークで回避せよ！

### 4. クリアボーナス階段（マルチプライヤー ×1.2 〜 ×5.0）
メガボスを討伐した後、生き残った味方たちがボーナス階段を前進！
到達した段数に応じて獲得コインが最大 **×5.0倍** に跳ね上がる最高に気持ちいいクリア演出！

### 5. フィーバータイム & 分かれ道
- 正解ゲート3連続で「🔥 FEVER TIME」発動！巨大化＆無敵超ダッシュ！
- 「⚠️ DANGER ZONE [×3]」vs「🛡️ SAFE ZONE [+5]」のハイリスクハイリターン分岐！

- **スマートフォン**: 左右スワイプ
